# 资源中心 · 任务管理

基于 **React 18 + Ant Design 5** 的高保真交互原型，覆盖任务列表、详情、状态机全链路。

## 技术栈

- React 18（UMD）
- Ant Design 5.22
- Day.js
- 无构建步骤，CDN 直出

## 本地预览

在项目目录启动静态服务（避免部分浏览器对本地脚本的限制）：

```bash
cd "/Users/haoting/Documents/cursor vibe design"
python3 -m http.server 5173
```

浏览器打开：http://localhost:5173

也可直接双击 `index.html`（需联网加载 CDN）。

## 业务链路

| 状态码 | 含义 | 需求方 | 供应商 |
|--------|------|--------|--------|
| 10 | 未受理 | 取消 | 受理 / 拒绝 |
| 20 | 已受理 | — | 上传成果 / 失败 |
| 40/50/60/90 | 终态 | 只读 | 只读 |

- 列表操作：**查看**（进入详情进行下一步）、**取消**（仅需求方 + 未受理）
- 右上角可切换 **需求方 / 供应商** 视角
- **供应商视角**：拍摄单位筛选禁用并锁定为当前供应商公司（`A公司`），列表/统计仅含本公司任务
- 「待我处理」Tab 按角色过滤待办
- 列表已移除「备注」列
- 任务详情「任务审批」中**任务受理 / 数据上传 / 任务完成**三环节支持供应商填写审批意见（任务创建无需填写）
